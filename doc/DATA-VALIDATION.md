# Severson 연구 기준 데이터 검증

## 목적과 근거

알고리즘 검증의 `데이터 검증`은 수명 추론 연구에 필요한 데이터 구조·기초 품질·시험 조건을 비교한다. 모델을 학습/실행하거나 현장 성능을 인증하지 않는다. 기준은 Severson et al., Nature Energy (2019), DOI [10.1038/s41560-019-0356-8](https://doi.org/10.1038/s41560-019-0356-8)의 10·100사이클 Q(V) 분산 기반 수명 회귀 입력이다. 5사이클 분류·전체 특징 모델을 혼합하지 않는다.

[논문](https://web.mit.edu/braatzgroup/Severson_NatureEnergy_2019.pdf)의 Data generation, Machine-learning approach, Methods를 기준으로 셀 모델·공칭 용량·챔버 온도·방전 조건, 공통 1,000지점, 수명 종료 정의를 기록했다. [공식 처리 코드](https://github.com/rdbraatz/data-driven-prediction-of-battery-cycle-life-before-capacity-degradation/blob/master/Load%20Data.ipynb)는 중단 시험 제외·배치 간 이어 측정 연결·잡음 채널 제외를 보여준다. 출처 URL과 앱 검사 규칙 버전을 보고서에 포함한다.

공개 용량 요약(기존 Severson 열화 이력)은 이 입력 곡선과 다르다. 정제된 분석 표본이나 연구의 예측 성능을 용량 요약에 부여하지 않는다.

## 입력과 판정

CSV 최대 5MB·20,000행. 브라우저에서만 검사한다. 표준 헤더의 V/Ah 단위를 요구하며 임의 단위 추정·보간·삭제를 수행하지 않는다. 파일명·SHA-256·검사 결과를 JSON으로 내려받는다. 원시 입력 행은 보고서에 포함하지 않으며 재현 시 원본 파일을 별도 보존해야 한다. 서버/브라우저 저장소에는 쓰지 않는다. 새 파일 선택 시 이전 결과를 제거한다.

입력 양식은 앱의 비교용 스키마다. 논문 공식 파일 형식이나 공인 산업 표준이 아니다. 기존 CSV를 지원 헤더·단위로 명시적으로 변환해야 하며 자유로운 컬럼 자동 매핑은 제공하지 않는다. XLSX와 원시 MAT 파일은 받지 않는다.

- 필수: cell_id, cycle, voltage_v, discharge_capacity_ah. 한 셀·사이클·전압 지점당 한 행.
- 조건: cell_model, chemistry, nominal_capacity_ah, chamber_temperature_c, discharge_c_rate, discharge_cutoff_v, charge_policy, rest_protocol, preprocessing_note, source_record. 각 행에 기재하며 모르는 값은 공란.
- 정답: cycle_life_cycles, eol_capacity_fraction, test_status(completed/censored). 특징 입력에는 선택이지만 성능 평가에는 필요하다.

`충족`은 해당 자동 검사만 통과했다는 뜻이다. `누락·보완`은 필수 컬럼·값·곡선 등의 부족, `조건 차이`는 레퍼런스와 다른 신고 조건, `확인 불가`는 기록 부족 또는 수동 대조가 필요한 근거다. 전체 합격 점수는 만들지 않는다. 조건 차이는 데이터 자체의 불량이 아니다.

10·100사이클 쌍은 셀별로 검사한다. 곡선 좌표는 전압 3.5–2.0V의 균등 1,000지점과 수치 허용오차 1e-6V로 비교한다. 이 허용오차는 소수점 직렬화를 위한 앱 기준이며 논문 계측 허용오차가 아니다. 전압 내림차순 누적 용량 역전은 1e-9Ah 수치 여유를 넘어가면 검토 대상으로 표시한다. 원 연구 보간법의 재현성·측정 정확도·원시 시간 순서를 인증하지 않는다. 소량 예제는 합성 미완성 자료로 표시하며 좌표 준비 부족을 의도적으로 드러낸다.

조건의 수치 비교는 신고값 기준이며 셀 모델·화학계는 대소문자 무시 문자열 비교다. 별칭 사전을 통해 자동으로 동일 모델임을 추정하지 않는다. 충전·휴지·전처리·출처 자유 서술은 존재해도 수동 검토가 필요하다. 셀별 고정 조건·수명 라벨 충돌을 점검한다. completed라도 전체 수명 이력의 진위는 자동 검증하지 않는다. 수명 중단은 종료 정답으로 대체하지 않는다.

원 논문 Table 1의 해당 variance 모델은 추가 평가 40셀에서 RMSE 196사이클, 평균 백분율 오차 11.4%를 보고한다. 화면의 수치는 원 논문 성적이며 앱의 검증 결과가 아니다.

## UI·격리·검수

연구 기준 / 파일 검사 / 비교 결과를 공통 ChoiceChips로 전환한다. 판정 필터별 한 항목과 다음 조치를 표시하고 페이지 버튼으로 넘긴다. 고정 인라인 스타일 없이 기존 색상·간격·타이포그래피·모서리 토큰을 사용한다. 컬럼 사전과 연구 상세만 펼쳐본다. 운영 재고·매칭·검사·승인으로의 쓰기 경로는 없다.

단위 검사: 정상 좌표, 조건 차이, 요약 자료의 스키마 부족, 셀별 사이클 누락, 중복·비유한값, 정답 충돌, 곡선 역전, CSV 형식·크기/행 제한. 브라우저 검사: 참조 안내, 합성 예제, CSV 교체·오류 후 결과 초기화, 보고서 출처·해시, PC·모바일 화면, 기존 공개 모델 접근.
