고객 제공 데이터 기반 비공개 체험

접근 및 보관
- 운영 화면의 '고객 데이터 체험'은 승인 사용자에게만 표시한다.
- private_demo_datasets는 승인 구성원만 SELECT할 수 있다. anon·승인 대기·정지 사용자 접근 및 authenticated 쓰기 금지.
- 파일 원본과 고객 측정값은 GitHub/public/dist에 포함하지 않는다. 로컬 정제 산출물은 .local에서만 취급한다.
- 원격 고객 자료 저장은 별도 승인 후 upload-private-demo.mjs로 수행한다. 운영 셀·팩·검사 테이블은 변경하지 않는다.
- 체험 데이터는 메모리에만 유지하고, 운영 화면 복귀·로그아웃·계정 변경시 폐기한다. 15초 및 포커스 복귀시 접근권한 재확인, 조회 실패시 체험 폐기.
- 승인 사용자의 명시적 보고서 다운로드는 가능하다. 다운로드 파일은 고객 자료이므로 공개 저장소에 넣지 않는다.

정제
- Cell Grading 88열/2단 헤더를 유지하고 초기 OCV D열과 방전용량 AO열을 사용한다.
- 128행을 보존하고 비교 가능 124행/보류 4행으로 구분한다. CurrentError 및 미완료 행을 정상화해 넣지 않는다.
- 원자료 내부저항·바코드·LOT 결측과 시간대 미확인을 보존한다. 파일 원본성·측정 단위·시험 조건은 고객 확인 대상이다.
- PoC 유효 셀의 전압·용량을 원행에 대조하고 기록된 팩의 편차를 재계산한다. K-means 실행 재현·현장 불량률 효과로 해석하지 않는다.
- 파일 내부 생성/수정 시각을 UTC 그대로 표시하고 실제 자료 제공일은 미확인으로 둔다. OS 파일 복사 시각을 제공일로 쓰지 않는다.

보완값 포함 업무 체험
- 고객 제공 전압·용량을 보존한다. 가상 내부저항 0.42 mΩ, 임시 ID·LOT·2000-01-01 시험 시각을 별도로 부여한다.
- 고정 내부저항은 추정값이 아니며 저항 편차를 0으로 만든다. 전체 SOP 통과는 보완값 포함 시험 결과이다.
- 모든 체험 팩은 synthetic, 검사 결과는 test로 분류한다. 운영 실측 성과에 집계하지 않는다.
- field_origins로 provided/supplemented/synthetic을 구별한다. 보완값은 보라색 배경과 문자 표식으로 셀 재고·자료 검토·승인 제출본·샘플 데이터 뷰에 표시한다.
- 원자료 검토 모드는 결측 그대로 비교하므로 전체 SOP 미검증 상태를 유지한다.

데이터 뷰
- 현장·관제 하단 '샘플 데이터'에서 전용 작업 영역으로 전환한다. 모달이 아니다.
- '원자료·사용값'에서 채널 검색, 원값과 사용값, 보완 여부를 비교한다. 작은 단말에서도 행을 넘겨 조회한다.
- '출처·날짜'에 파일별 메타정보와 해시를 둔다. '업무로 돌아가기'는 기존 화면과 작업 상태를 유지한다.
- 공개 합성 체험에도 동일 뷰를 제공하되 고객 데이터를 포함하지 않는다.

검증
- demoData.test.ts: 결측 원본 불변, 보류 제외, 제공/보완 필드 구분.
- test-database.mjs: 비공개 테이블의 승인 사용자 조회, 비승인 조회 차단, 클라이언트 수정 차단.
- private-demo.spec.ts: 합성 fixture로 값별 표식·출처·좁은 화면·업무 복귀·쓰기 없음·권한 회수 검증.

전체 원자료 조회
- 샘플 데이터의 전체 항목에서 원래 컬럼명과 데이터 값을 표시한다. 엑셀 열 문자·행 번호나 서식은 재현하지 않는다.
- 충방전 파일은 2단 헤더를 컬럼 제목으로 표시하고 128건을 보존한다. PoC는 첫 품질 기준 설명 탭을 제외한 2~4번째 탭의 모든 컬럼·값을 표시한다.
- 컬럼명 중복은 충방전 단계 부제와 원래 순서로 구분한다. 빈칸·앞자리 0·보류 행을 유지하고 숫자 표시를 반올림하지 않는다. 날짜 셀은 시간대 추정 없이 날짜·시간 문자열로 표시한다.
- 20건씩 조회하며 데이터 파일·시트를 바꾸면 첫 페이지로 돌아간다. 원자료 저장본은 source_tables 필드에 보관하며 공개 번들에는 포함하지 않는다.

운영 복귀와 도움말
- 고객 데이터로 비공개 체험 제목 위 홈 아이콘은 운영 화면으로 돌아간다. 체험 선택·출처 탭과 분리한다.
- 체험 작업의 체험 종료는 선택 화면으로, 샘플 조회의 업무로 돌아가기는 진행 중인 체험 작업으로 복귀한다.
- 화면 매뉴얼과 Docs는 같은 안내와 캡처를 사용하며 전체 항목 조회와 홈 복귀 경로를 포함한다.
