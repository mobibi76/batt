UX/업무 흐름 구성 기준 (2026-10-15)

적용 목적
작업 범위.txt의 실제 수행안(실증 준비형 MVP)을 기준으로 데이터 등록, 셀 매칭, 팩 구성, 공정 검사, 독립 품질 승인, 이력 조회를 연결한다. 모델 학습·생산 성과·실장비 관제 완료를 뜻하지 않는다.

첫 화면과 정보 우선순위
- 현장: 담당자가 처리할 팩 하나, 판단 사유, 에이징/최종검사 상태, 다음 업무 버튼.
- 승인권자: 독립 검토 가능한 제출본. 관리자 권한만으로 승인권을 부여하지 않는다.
- 관제의 관리자/조회자: 최신 품질 지표부터 확인. 공정 공간은 명시적인 화면 전환으로 접근한다.
- 공정 공간의 개인 설계 배치와 실제 장비 신호 미연결 표시는 유지한다.
- 실측/시험/혼합 집계와 고객 제공값/시험 보완값의 구분을 줄이거나 숨기지 않는다.

업무 연결
- 대기 대상이 있으면 첫 대상의 근거를 바로 표시한다. 이는 자동 검사·자동 승인과 다르다.
- 입력을 시작하면 해당 팩을 유지한다. 선택한 팩이 목록에서 사라진 경우 상태 변경을 알리고 다른 대상을 명시적으로 선택한다.
- 검사 입력의 기본 공정은 담당 권한과 최신 검사 상태로 결정한다. 에이징 완료 후 최종검사, 불합격 시 해당 공정 재검사를 우선 안내한다.
- 두 검사가 완료된 팩은 검사 입력을 반복시키지 않고 같은 팩의 품질 검토 요청으로 연결한다.
- 누락 검사 확인은 현재 지표 집계 범위와 미연결 필터를 전달한다. 전체 팩 보기는 사용자가 명시적으로 선택한다.
- 셀·조합 바로가기는 셀 매칭으로 연결한다. 매칭 가능한 셀이 있고 팩이 없으면 조합 검토·팩 구성을 다음 업무로 안내한다.

검증과 유지 기준
- workflow.test.ts: 다음 검사 선택, 공정 담당 권한, 관리자와 승인권자 분리.
- console.spec.ts: 첫 판단 대상 표시, 동일 팩의 에이징→최종검사→검토 요청, 미연결 조회 조건 유지.
- 기존 승인/재검사/역할/고객 체험/공정 설계 검사를 보존한다.
- control-labels.spec.ts와 design.spec.ts는 배포 전 필수 검사다. 모바일에서 단어 분리·넘침이 발생하면 배포를 차단한다.
- 새 기능은 사용자의 다음 판단에 필요한 위치에 배치한다. 정보와 메뉴 수를 기능 수에 비례해 늘리지 않는다.

입력 집중과 피드백
- 검사 입력 중에는 업무 전환 메뉴와 하단 이동 버튼을 숨긴다. 입력 닫기/저장 완료 후 복구한다. 저장 실패 시 입력을 보존한다.
- 판단 사유와 실행 버튼을 하나의 카드로 묶고 읽기 폭을 공통 토큰으로 제한한다.
- 셀 등록/팩 확정의 성공 피드백은 기존 다음 업무 안내로 제공한다. 중복 토스트는 제거한다.
- 현장 검사 저장 후 갱신된 팩 상태를 읽기 보조 도구에도 알린다. 오류와 별도 권한 변경 알림은 유지한다.

요청형 화면 설명과 DOCS (2026-10-15)
- 평소에는 사용 안내 버튼만 제공한다. 자동 팝업·첫 방문 튜토리얼·상시 설명 카드는 사용하지 않는다.
- 요청 시 설명 모드에서 실제 요소를 강조하고 업무 입력을 잠시 막는다. 설명을 닫아도 원래 화면·작성 값은 유지된다. 배경의 데이터 갱신이나 이미 시작한 가상 실행을 정지시키는 기능은 아니다.
- 설명 항목은 순차 학습을 강요하지 않고 직접 선택한다. 현재 화면에 없는 항목은 없다고 명시하며 화면을 자동 전환하지 않는다.
- DOCS는 13개 업무 시나리오의 담당자·시작 조건·처리 순서·판단 기준·예외 대응·완료 상태를 제공한다. 검색, #docs/시나리오 링크, 전체 인쇄·PDF 저장을 지원한다.
- 설명과 DOCS의 단일 원본: src/manual/content.ts. 공통 UI: UserManual.tsx, 스타일: manual.css, 제품 토큰: design-tokens.css.
- DOCS는 읽기용으로 스크롤할 수 있다. 현장·관제 작업 화면의 공간은 차지하지 않는다. 공개 매뉴얼에는 고객 측정값·계정 정보가 포함되지 않는다.
- 로그인/권한 대기, 현장/관제 상세 업무, 고객 체험 입구에 연결한다. 서버 권한과 검사·승인 로직은 수정하지 않는다.
- manual.spec.ts에서 입력 보존, 실제 요소 강조, 작은 화면 닫기/복귀, 검색, 인쇄 범위, 비로그인 직접 링크, 가상 공정 화면 크기 전환을 검증한다.
