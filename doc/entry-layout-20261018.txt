2026-10-18 타이틀·생산 진입·연구 레이아웃 개선

요구 반영
1. 로그인 타이틀의 이미지 높이와 여백을 화면에 맞춰 배분했다. 로그인은 1440×900, 1366×768, 1024×600, 390×844, 390×600, 320×480에서 문서 스크롤 없이 로그인·체험 버튼을 표시한다. 가입 화면은 높이 600px 이상에서 같은 기준을 검사한다. 극소 화면·확대·긴 오류 안내는 조작을 자르지 않는다.
2. 공개 체험은 생산 작업으로 진입한다. 빈 재고의 측정 파일 등록 시작은 파일 가져오기로 연결된다. 일반 로그인도 생산 작업을 기본으로 유지하며, 별도로 선택한 비공개 고객 데이터 체험의 기존 자료 검토 맥락은 보존한다.
3. 연구 공정 설계/시뮬레이션 전환과 공정 승인함을 공통 작업 제목 줄로 옮겼다. 별도의 본문 메뉴·상시 안내 줄을 제거했다. 편집·저장 상태는 공정도 하단 설명 자리에서 표시해 작업 중 화면이 밀리지 않게 한다. 모바일에서는 승인함을 제목 옆, 두 모드를 다음 한 줄에 배치한다.
4. 일반 PC의 공정도와 편집부 높이를 맞추고 공정 전체 스크롤을 없앴다. 긴 편집 내용의 내부 스크롤은 유지한다. 높이 450px 이하에서는 제목과 편집부를 함께 이동할 수 있어 버튼이 잘리지 않는다.

검증
신규 entry-layout.spec.ts는 타이틀/가입의 화면 경계, 생산 작업 선택 상태와 첫 등록 버튼, 연구 도구 위치, 공정 전체 스크롤, 모드 왕복 시 장비 이름 보존을 확인한다. 기존 역할별 시나리오는 공개 체험에서 셀 검사·재고를 명시적으로 선택하도록 갱신했다. 검사 조건을 생략하지 않았다.
기존 전체 148건 검사에서 발견한 320px 메뉴 줄바꿈과 구 진입 경로 의존을 보완했다. 관련 검사 45건 재실행에서 320×360 편집부 축소 문제를 추가 발견해 극소 화면에 한정해 보완했다. 최종 결과는 해당 커밋의 GitHub Actions와 로컬 test-results를 참조한다.

문서
화면 도움말, README, 디자인 원칙과 타이틀·공정 설계 매뉴얼 캡처를 새 동선에 맞춰 갱신한다. 합성 자료만 사용하며 운영 DB·고객 측정값·품질 판정 로직은 변경하지 않는다.
