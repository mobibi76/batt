# 연구 출처 링크의 대체 자료

수명·안전성 연구 준비의 공개 연구 출처 링크 9개를 `SourceReference` 컴포넌트로 통일했다. 원본 링크 옆의 **앱 내 보관 자료**를 열면 출처와 보관 범위를 확인·내려받을 수 있다. 외부 페이지의 장애 여부를 추정하거나 임의 사이트로 자동 이동하지 않는다.

| 출처 | 보관 범위 |
|---|---|
| UConn 원본 데이터 | 전처리에서 추출한 55셀 표본·출처·변환식. 원시 데이터 전체 아님 |
| UConn 전처리 저장소 | 고정 커밋·표본·원본 ZIP 해시·MIT 고지 |
| UConn 모델 | 사용 계수·원본 C++ 파일·MIT 고지 |
| UConn 특징값 | 112개 사용 입력·선정 규칙·원본 ZIP 해시. 전체 ZIP 아님 |
| UConn 라이선스 | MIT 저작권·허가 전문 |
| Severson 데이터 포털 | 앱에서 사용하는 공식 용량 요약 전체·배치 주의사항·원출처 및 파일 해시 |
| Severson 논문 PDF / DOI | 연구 목적·조건·전처리·평가 결과의 사실 요약·원문 위치·DOI·PDF 해시 |
| Severson 정제 코드 | 고정 커밋·노트북 해시·실제 정제 절차의 사실 요약 |

논문·Severson 노트북 전문은 공개 재배포하지 않는다. 사실 요약은 앱 작성자의 정리이며 저자 인증본이 아니다. 해시는 내용 식별용이지 사라진 원본을 복구하는 수단이 아니다. 이번 확인에 사용한 원문 PDF·노트북은 개발 PC의 `.local`에 있으나 해당 임시 폴더를 장기 보관 또는 배포 fallback으로 계산하지 않는다.

`referenceArchive.json`, `seversonEvidence.ts`, 배포 파일들은 Git 이력으로 고정된다. UConn 소스는 커밋 `10d7bd9ca6d39378406e406e43d2a083575b77ca`, Severson 정제 코드는 `1ef13d27c66dc3d73affdaa008fbeba5687b2ea4`에 연결한다. 데이터 검증 보고서에는 Severson 근거 요약도 포함한다. 다른 출처는 개별 출처·보관 범위 보고서를 받을 수 있다.

## 화면 위치

연구 문헌 아래 `공개 데이터의 출처와 측정 차이`에서 UConn 원본·전처리 출처를 확인한다. 모델·특징값·이용허락은 UConn 문헌의 공개 모델 참고 도구 안에, Severson 용량 출처는 열화 이력 참고 도구 안에 있다. 논문·DOI·정제 코드는 Severson 데이터 준비 비교의 추가 상세 검사에서 확인한다. 문헌 등록·스키마 충족은 고객 팩의 수명·안전성 검증 완료를 뜻하지 않는다.

## 변경·무결성

`scripts/prepare_reference_archive.py`가 로컬 데이터·모델·라이선스·원문 C++의 SHA-256을 계산하고 목록을 만든다. C++ 파일은 기존 모델 출처 해시와 일치해야 복사한다. 원문 업데이트는 자동 수용하지 않고 확인 후 근거 버전을 올린다. 원문 대조 없이 날짜나 해시만 최신값으로 교체하지 않는다.

보관 파일 다운로드는 앱 서버에서 가져온 바이트를 SHA-256으로 확인한다. 누락·조회 실패·버전 불일치면 다운로드를 막고 오류를 표시하며, 번들에 포함된 출처 요약은 그대로 제공한다. 외부 사이트가 사라져도 앱에 보관한 범위는 사용할 수 있다. 다만 앱 서버까지 끊긴 상태의 신규 접속을 지원하는 PWA 전체 오프라인 모드는 아니다.

검수: 9개 링크 연결 누락 방지, 배포 파일 해시, 고정 커밋·보고서 근거 포함, 외부 네트워크 차단 상태의 출처 보고서 다운로드, 라이선스 원문 다운로드 및 변조 파일 거부, 모바일 폭.
