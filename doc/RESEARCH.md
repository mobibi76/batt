# 데이터·AI 검증의 두 테마

1. 현장 판단 학습·8셀 조합: 고객 측정값과 작업자 판단·근거·검사 PASS/FAIL을 연결해 현장 기준을 학습하고 8셀 조합을 찾는 연구. 현재 제공 기능은 고정 알고리즘 조합 비교와 실험 기록이다. 판단 데이터 학습·독립 성능 검증·학습 모델 추론은 후속 구현이며, 기존 비교를 AI 학습 결과로 표시하지 않는다.
2. 수명·안전성 연구 준비: 문헌·제공 데이터셋 출처·입력 스키마 등록 → 연구 선택 → 고객 CSV 비교 → 추가 확보·값 보완·수동 확인 항목 안내. 수명·안전성 추론 실행은 범위에 포함하지 않는다.

스키마는 버전, 데이터셋 URL, 측정·전처리 근거, 열 이름·설명·단위·자료형·역할(입력/조건/정답)·필수 여부로 구성한다. UConn은 현재 용량 모델의 특징값 기준, Severson은 10·100사이클 Q(V) 비교 양식을 기본 제공한다. 둘 다 원시 데이터 파일 형식 자체와 동일하다고 주장하지 않는다. 선택 문헌이나 스키마가 바뀌면 고객 데이터 비교 결과를 초기화한다.

고객 CSV는 브라우저에서만 검사한다(5MB, 20,000행). 열 존재·빈 값·수치 형식을 비교하며 미일치 열은 새로 측정하기 전 기존 열 대응·단위 변환 가능 여부를 확인하도록 안내한다. 단위·측정 조건·반복 이력·정답의 적합성은 자동 인증하지 않는다. Severson은 같은 문헌 안에서 기존 곡선·사이클 상세 검사를 추가로 제공한다. 보고서에는 문헌 식별·스키마 스냅샷·원본 해시·항목별 후속 조치를 담고 원시 고객 값은 포함하지 않는다.

문헌이 있어도 스키마가 없으면 비교할 수 없음을 표시한다. 스키마 등록은 원문에 대한 검증 완료나 모델 실행을 뜻하지 않는다. 로그인 환경은 202610170003_research_schema.sql 적용 후 웹을 배포한다. 기존 문헌은 스키마 미등록 상태로 보존된다.

## 현재 테마 1 작업 흐름 (2026-10-18)

현재 측정·판정 자료 가져오기는 작업공간에서 조회한 셀·팩·검사의 읽기 전용 스냅샷이다. 전체 고객 자료를 모두 읽었다는 뜻이 아니다. 고객 CSV도 출처·이용 조건·측정 조건과 함께 가져온다. 원행의 결측·중복·잘못된 값은 보존하고 준비 상태에 반영한다. 공개 UConn 55셀은 기본 입력이나 현장 학습 자료가 아니며 기존 실험 재현 근거로 보관한다.

1. 연구 데이터: 전압·내부저항·용량 분포, 결측, 셀 작업자 판단과 연결 팩 검사를 확인한다. 선택한 원행의 출처·보완 여부를 확인할 수 있다. 재고 상태는 PASS/FAIL이 아니고 팩 검사는 셀 라벨이 아니다.
2. 비교 조건: 8셀 구성·검사 종류별 팩 판정의 기초 연결과 부족 항목을 확인한다. 팩 근거를 열고 설정으로 돌아온다. 모델 학습·시험 분할·추론 정확도는 미구현이다. 합성·보완값 포함과 조건 그룹, 허용 편차·시드를 명시적으로 정한다.
3. 검증 결과: 선택 후보의 편차와 구성 8셀을 먼저 확인한다. 전체 알고리즘 비교를 펼쳐 같은 입력의 방법별 결과를 비교한다. 무작위 순서 대조군은 현장의 기존 작업 방식이 아니다. 5회 범위는 입력 순서 민감도이며 신뢰구간이나 모델 정확도가 아니다.
4. 운영 적용 검토: 연결된 기존 팩 구성·검사 사례와 적용 전 추가 검증을 확인한다. 연구 후보가 검사 합격이나 운영 적용을 뜻하지 않는다.

보고서는 원행 스냅샷·실제 실행 대상·준비 조건·설정·해시·반복별 결과를 보관한다. 고객 비공개 체험은 메모리에만 유지한다. 일반 합성 체험의 최근 실험과 실제 로그인 사용자의 서버 저장 권한을 구분한다. 모바일에서는 분석 근거와 입력·선택 상세를 같은 위치에서 전환한다.

# 공개 연구 표본과 기존 비교 이력 (보관 근거)

운영 셀·팩·검사 DB에 쓰지 않는 브라우저 연구 공간이다. 승인된 사용자(관리자/작업자/조회자)와 합성 데이터 체험 사용자가 접근할 수 있다. 사용자는 자료를 고르고 연구용 허용 편차와 시드를 정한 뒤 알고리즘을 비교한다. 체험 보고서는 사용자 ID별 브라우저 localStorage에 최근 10개를 보관하며 다른 PC와 동기화하지 않는다. 실제 로그인 사용자는 권한에 따라 서버에 실행 보고서를 저장하고 본인의 최근 10개를 조회한다. 조회 권한은 새 실행을 서버에 저장하지 않는다. JSON 내려받기로 원본 표본과 결과를 보존할 수 있다.

## 비교 엔진

`src/research/engine.ts`, 버전 `research-matching-1.0.0`.

1. `sequence-v1`: 고정 시드 Fisher–Yates 순열을 8개씩 묶는 대조군.
2. `capacity-sort-v1`: 같은 셀을 용량 오름차순으로 묶는다. 동점은 ID로 처리한다.
3. `multi-start-nearest-v1`: 각 셀을 시작점으로 허용 편차로 정규화한 세 변수 거리의 근접 셀을 탐색한다. 그룹에 추가할 때마다 세 편차의 상한을 확인한다. 가능한 8셀 그룹 중 평균 정규화 편차가 가장 낮은 그룹을 확정하고 사용 셀을 제거한다. 전역 최적 팩 수나 최적 비용을 보장하지 않는다.

동일 입력·허용 편차에서 각 알고리즘을 시드 s..s+4로 반복한다. 이것은 동일 셀의 순서 민감도를 보는 것이며 독립 표본 5배, 교차검증, 신뢰구간 또는 확정 시험 성능이 아니다. 모든 그룹은 배치/조건 cohort 내부에서 생성한다. 8셀 미만 그룹은 제외 사실을 표시한다. 8셀만 있는 그룹은 조합 선택의 여지가 없다.

현재 기본 연구 상한은 10mV / 5mΩ / 500mAh이며 연구 설정이다. 운영 SOP v2는 전압·용량을 판정하고 내부저항은 선택 참고값이다. 연구 기준을 운영 기준으로 자동 승격하지 않는다.

적합 팩 비율은 적합 팩 수 / floor(입력 셀 수 / 8). 미배정 셀은 입력 셀 수 - 적합 팩 수 ×8. 평균 편차는 적합 그룹만의 평균이므로 반드시 확보 팩 수와 같이 비교해야 한다. 미배정 셀을 감춰 좋은 편차만 주장하지 않는다. 실행시간은 클라이언트 하드웨어와 워커 실행 환경에 의존한다.

## 추가 자료 및 운영 이관

고객 측정 CSV: `id,cohort,voltage_mv,resistance_mohm,capacity_mah` (`cohort` 대신 `lot` 가능). 최대 5,000 원행, 2MB 이하. 결측·오류 행을 원행으로 보존하고 준비 조건을 충족한 8–300셀만 비교한다. 출처·라이선스·측정 조건을 입력해야 한다. 단위·물리 셀의 동일성·cohort 비교 가능성은 원자료와 대조해야 한다. 사용자 CSV는 출처가 독립 검증된 데이터로 표시하지 않는다.

Severson 공식 용량 요약은 별도 열화 이력 화면에 탑재했다. 3변수 조합용 전처리와 수명 예측은 미구현이다. 초기 구현 기록에는 관련성이 없거나 불필요하여 제외했다는 판단이 없다. 필요한 전압·저항·용량의 존재와 측정 시점·조건을 확인한 후 연구 CSV로 변환해야 한다. 수명·열화 연구와 관련성이 있지만 현장 팩 불량 라벨을 대신하지 않는다. 원 논문: https://www.nature.com/articles/s41560-019-0356-8 . 24V 8직렬 실사용 데이터와 AI Hub 결함 이미지는 다른 연구 과제(시계열 이상탐지·영상 검사)이며 이 조합 엔진에는 연결하지 않았다.

보고서는 입력 전체와 데이터 SHA-256, 소스 버전, 엔진 버전, 조건, 시드, 반복별 조합·편차·판정·시간을 포함한다. 운영 적용은 현장 독립 LOT 비교, 실제 팩 검사 라벨, 측정법과 제품 규격의 적합성, 운영 서버 SOP 재검증을 거쳐 별도 변경으로 진행한다. 검증 모드의 버튼으로 운영 알고리즘을 바꾸지 않는다.

검증: `npm test` 및 `npm run test:e2e`. 재현성, 셀 중복 방지, 조건 상한, 다른 배치의 혼합 차단, 잘못된 입력 차단, 파일 내보내기와 이력 복구, 운영 지표 격리를 포함한다.

## 2026-10-15 공개 표본 재현 기록 (현재 기본 입력 아님)

당시 3변수 조합 비교의 기본 제공 공개 표본은 UConn 전처리 자료 기반 55셀이었다. 현재는 고객 측정·판정 자료가 입력 경로다. 연구진 CSV에서 재추출한 내용과 앱 표본이 일치함을 확인했다. 대학 원시 계측부터 전처리 전체를 재현했다는 뜻은 아니다. 같은 배치라도 SOC·시험 그룹이 다르고 온도 정보가 없어 조건의 완전한 일치를 보장하지 않는다.

당시 연구 상한 10mV / 5mΩ / 60mAh에서 각 배치 전체 편차가 상한보다 작아 모든 8셀 조합이 통과한다. 기본 시드 20261014와 이어지는 4개 시드에서 세 알고리즘 모두 배치별 2/3/1개 조합이 적합하다. 적합률만으로 우열을 주장할 수 없으며 미배정 셀·개별 편차를 함께 비교해야 한다. Batch 3은 8셀뿐이라 조합 선택의 여지가 없다. 적합 판정은 연구용 편차 충족이며 실제 팩 검사 합격이 아니다.

- 프로젝트: https://data.matr.io/1/api/v1/edp/projects/5c48dd2bc625d700019f3204
- 논문: https://doi.org/10.1038/s41560-019-0356-8
- 생성: `node scripts/fetch_severson.mjs`, 결과: `public/research/severson-capacity.json`.
- 3개 배치, 140개 시험 기록, 바코드 기준 고유 셀 135개, 이어 측정 기록 5개. 논문의 분석용 124셀 선별 집합을 재현한 것이 아니다. 조기 종료·노이즈 등 공식 주의사항을 함께 제공한다.
- API의 방전용량 y.data를 Ah에서 mAh로 변환해 0.001mAh로 반올림했다. 순서와 초기 과도값을 보존한다. 명시적인 x 좌표가 없어 가로축은 기록 순번으로 표시하며 실제 cycle 번호로 단정하지 않는다.
- 물리 셀 바코드가 같은 후속 배치를 새 독립 셀로 계산하지 않고 continuation_of로 표시한다. 이력을 임의 접합하거나 마지막 점을 수명 종료 라벨로 사용하지 않는다.
- 원자료 API URL과 응답 SHA-256, 수집 시각, 조건, 변환 설명을 기록한다. 선택 기록을 JSON으로 내려받을 수 있다. 데이터는 브라우저에서 읽기만 하며 생산 DB·승인·품질 지표와 분리한다.
- 요약에는 전압·저항이 없어 기존 3변수 비교에 넣지 않는다. 공칭 3.3V 등을 측정값으로 대입하지 않는다. 현 단계의 가치는 실제 용량 변화·시험 중단·배치 차이·계속 측정 여부를 검토하는 것이다. 학습이나 현장 효과 실증은 수행하지 않는다.

## 공개 연구의 목적과 향후 팩 연구 등록

UConn의 현재 활용 모델은 셀이 현재 어느 정도의 용량을 유지하는지 추정한다. Severson 원 연구는 셀의 수명 종료까지 총 사이클 수를 예측한다. 앱의 Severson 기능은 용량 이력 조회이며 예측 모델 실행이 아니다. 두 연구는 수명·안전성 연구의 참고 자료로 활용한다. 직접적인 안전성 추론 근거, 고객 셀 적용 검증, 조합한 팩의 수명·안전성 검증으로 표시하지 않는다. 이 구분은 화면의 상시 안내와 내려받는 결과에도 유지한다.

향후 연구 등록 기능은 조합한 팩의 수명·안전성을 추론할 수 있는 검증된 연구를 대상으로 확장한다. 문헌 검색·등록·수정·삭제와 분류 기능은 구현했다. 아래 항목 중 독립 심사, 고객 팩 검증 완료 판정, 모델 실행 연결과 운영 승인은 후속 구현 범위이다.

- 연구 식별: 제목, 저자, 논문/원출처, 모델·데이터 버전, 이용허락.
- 예측 목적: 셀/팩 단위, 현재 용량/총 사이클 수명/잔여 수명/구체적인 안전성 지표를 구분한다. 수명 검증을 안전성 검증으로 대신하지 않는다.
- 적용 조건: 셀 화학계·규격, 팩 직병렬 구성, BMS·열관리, 운전·시험 조건과 적용 제외 범위.
- 입력 계약: 필요한 측정 항목·단위·주기·전처리, 셀과 팩 식별·구성 이력, 고객 데이터의 확보 여부.
- 검증 근거: 정답과 수명 종료/이상 사건의 정의, 독립 시험 집합, 표본 수, 평가 지표·오차·불확실성, 재현 자료. 원 연구의 검증과 고객 팩에서의 검증을 별도로 기록한다.
- 활용 상태: 참고 자료 → 적용 후보 → 고객 팩 검증 완료를 구분한다. 논문 등록만으로 검증 완료 또는 운영 사용 가능 상태가 되지 않는다.
- 실행·이력: 모델 버전과 입력·조건·출력·적용 한계를 보존한다. 연구 등록과 운영 적용 승인은 분리한다. 검증 범위 밖의 팩은 추론 적용 대상에서 제외하고 부족한 조건을 안내한다.
## 문헌 중심 연구 화면 (2026-10-17)
