주성산업 역할별 사용자 시뮬레이션 및 정리 — 2026-10-18

범위와 방식
Chrome 브라우저에서 합성 체험 자료와 격리된 서버 응답을 사용한다. 역할별 연속 작업은 1366px·390px, 하단 접근은 320×360·320×480·900×360·1366×600·1366×768에서 확인한다. 실제 운영 DB와 고객 자료는 변경하지 않는다. 서버 권한과 승인 원자성은 별도의 격리 PostgreSQL 검사로 확인한다.

생산자
오류 CSV 등록 차단 → 정상 측정 파일 등록 → 128셀 재고 확인 → 셀 보류 → 보류 셀 제외 8셀 조합 → 팩 확정 → 모듈 검사 → 케이싱 → 최종검사 → 불합격 기록 → 재검사 → 품질 검토 요청.
재고 검색·페이지 복귀, 검사 저장 실패 시 입력 보존, 셀 중복 사용 방지, 검사 담당 공정 권한을 함께 검사한다.

품질 관리자
동일 팩의 검사·조치 근거 조회 → 별도 승인권자 검토 → 의견 작성·목록 복귀 → 승인 또는 반려 → 품질 결과·이력 확인.
자기 승인 및 시스템 관리자의 품질 승인 차단, 재검사 후 기존 승인 무효화, 반려·재제출, 검토자별 초안 분리를 확인한다.

연구자
테마 1: 현재 측정·작업자 판단 자료 가져오기 → 준비 상태 확인 → 조건별 고정 알고리즘 조합 비교 → 결과·보고서 내보내기 → 동일 조건 재실행·실험 이력 재개. 학습 모델을 구현한 것으로 표시하지 않는다.
테마 2: 문헌 검색·직접 등록 → 데이터셋 출처·스키마 입력 → 고객 CSV 비교 → 누락 항목과 준비 상태 보고서 → 수정·삭제. UConn 현재 용량과 Severson 총 사이클 수명은 셀 수명 참고 연구이며, 팩 안전성 검증을 뜻하지 않는다.
공정 설계: 장비 추가·편집·삭제·삭제 취소 → 작업 순서 보기와 편집 복귀 → 확보 데이터 선택 → 개인 저장·내보내기 → 시간·병목 시뮬레이션 → 독립 승인 → 생산·품질 반영. 기존 팩의 공정 버전은 보존한다.

발견 및 보완
역할별 연구 화면 캡처에서 공정 설계/시뮬레이션 전환 순간 버튼 글자가 배경과 같은 색으로 보이는 현상을 발견했다. 글자색은 즉시 변경되지만 배경색만 150ms 전환되어 명암 대비가 최저 1:1로 떨어졌다. 공통 .mode-switch 버튼의 배경 전환을 제거하여 두 색이 함께 바뀌게 했다. PC·모바일에서 양방향 전환의 프레임별 대비를 검사하는 tests/mode-contrast.spec.ts를 추가했다. 편집 값, 공정 계산, 승인 로직은 변경하지 않는다.

정리
내용을 확인한 과거 CI 추적·오류 보고서·스크린캐스트 폴더 8개와 압축본 4개에서 1,821개 파일(254.64MiB)을 제거했다. 고객·연구 원자료, 라이선스, DB 마이그레이션, 재현 스크립트, 현재 검사 증빙은 보존한다.
현재 카탈로그·소스·문서에서 참조하지 않는 매뉴얼 이미지 research-field-preparation.png, research-field-readiness.png, research-field-results.png, research-uconn-data.jpg를 제거했다. 현재 매뉴얼의 54개 이미지 참조는 모두 존재한다.

검증 한계
합성 시뮬레이션은 실계정 서버 저장, 실제 장비 연동, 고객 팩의 수명·안전성 검증을 대신하지 않는다. 2026-10-17 기록은 당시 검증 이력이며 현재 연구 동선은 본 문서를 기준으로 읽는다.

실행 결과
수정 전 기존 브라우저 전체 137건 통과(5.2분). 전환 대비 신규 검사는 수정 전 실패하여 결함을 재현했다. 보완·파일 정리 후 새 빌드에서 신규 대비 2건을 포함한 역할·공정·매뉴얼 35건이 모두 통과했다(1.0분). 단위 82건, 격리 DB 통합검사, 19 CSS/174 토큰 디자인 검사, TypeScript/프로덕션 빌드가 통과했다. 역할별 PC·모바일 캡처와 수정 후 버튼 캡처를 확인했다. 증빙은 test-results/에 보관하며 Git에는 합성 테스트 코드와 본 기록만 포함한다.
