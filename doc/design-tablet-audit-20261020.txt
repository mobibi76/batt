2026-10-20 batt 공통 스타일·태블릿 점검

범위
- batt 제품만 적용. 다른 제품과 디자인 시스템을 통합하지 않음.
- 로그인·가입·대기, 공개 체험·비공개 고객 자료, 생산 셀 재고·조합·팩 검사,
  품질 이력·보고서·승인, 연구 데이터 비교·문헌·스키마·공정 설계,
  사용자 관리, 고객 데이터 튜토리얼, 화면 설명·DOCS·인쇄.
- 데스크톱 및 가로·세로 태블릿 지원. 스마트폰 지원은 범위 밖.
  현장 안전 정책에 따라 폭 768px 미만은 미지원 안내만 표시하고 조작 차단.
  기존 작은 화면 업무 검사는 지원 대상 태블릿 폭으로 전환.

스타일
- src 전체의 22개 CSS 및 TS/TSX를 검사. 토큰 이름 177개.
- 색상·글꼴·간격·모서리의 제품 공통 기준과 로그인·매뉴얼 고유 팔레트 유지.
- 중복 상세 패널 폭, 인스펙터 폭, 좁은 컨트롤 폭을 공통 토큰으로 이동.
- 미사용 아이콘 클래스·토큰, 덮어쓰인 제목 자간, 중복 로그인 색상 제거.
- 고정 JSX 스타일 대신 클래스 사용 여부를 TypeScript 구문 분석으로 검사.
  별칭 객체에 숨겨진 고정 스타일과 잘못된 imperative style 변경도 검사.
- 실행 중 좌표·비율만 등록한 CSS 변수로 허용:
  화면 설명·캡처 강조 위치, 시뮬레이션 시간축, 연구 분포·편차, 3D 라벨 투영.
- Three.js/Recharts의 자체 기하 계산·캔버스·고유 표시와 원래 의미 색상 유지.

태블릿
- 768×1024 / 1024×768, 800×1280 / 1280×800,
  834×1194 / 1194×834에서 터치 환경으로 검증.
- 960px 이하의 작업대는 상세 전환 사용. 조작 대상 최소 높이 44px.
- 셀 재고 표는 실제 패널 너비에 따라 카드 배치로 전환.
  가로 1024px의 좁은 우측 작업 패널에서 발견한 넘침 해결.
- 세로 DOCS 목차 폭 조정, 공정도 높이 조정, 낮은 화면에서 스크롤 접근 보장.
- 회전 시 팩 선택·일련번호·검토 사유·미저장 검사 메모 유지.
  1024×500 가용 화면에서도 검사 저장 버튼 접근·클릭 검증.
- 9개 작업 화면과 DOCS의 6개 크기 배치, 생산→품질 및 연구 동선 확인.
- 매뉴얼 캡처는 로컬 합성 자료로 재생성. 고객 원본은 캡처하지 않음.
