주성산업 역할별 사용성 검증 및 개선 기록 — 2026-10-17

검증 방식
Chrome에서 PC 1366px, 모바일 390px의 실제 화면을 조작했다. 320×480 화면에서 재고 이동 및 주요 화면의 잘림도 별도로 확인했다. 파일 선택·다운로드·입력·탭 전환을 사용했으며 공개 가상 체험 데이터와 공개 연구 자료로 수행했다. 실계정 로그인, 운영 서버 저장, 실제 장비 연동을 완료했다는 뜻은 아니다. 승인 권한과 데이터 보존은 별도의 로컬 DB 통합검사로 확인했다.

1. 생산 작업자
정상/오류 CSV 등록 → 용량별 재고 확인 → 셀 보류 → 보류 셀을 제외한 8셀 조합 → 모듈 검사 → 케이싱 → 최종검사 → 불합격 조치와 재검사 → 품질 검토 요청.
개선: 셀 ID 다음에 용량·상태를 배치했다. 모바일에서는 측정값을 두 열로 읽으며 가로 스크롤 없이 검토 버튼을 누를 수 있다. 한 페이지 1셀을 6셀로 바꾸고 페이지 이동을 유지했다. 작은 화면에서는 체험 안내와 실제 작업을 같은 영역에서 스크롤할 수 있다.

2. 품질 관리자/별도 승인권자
불합격 팩 조회 → 재검사 근거 확인 → 독립 검토 → 의견과 승인 → 품질 결과 및 팩 이력 확인. 반려·재제출, 검사 변경 후 이전 승인 무효화도 회귀검사했다.
개선: 승인 요약과 출처 안내에 케이싱 검사를 포함했다. 모바일 근거 화면에서 최종 판단으로 이어지는 버튼을 추가했다. 승인 뒤 품질 결과 버튼은 어느 탭에서도 접근할 수 있다. 승인·반려·검사 변경 상태에 맞춰 판단 요약 제목을 표시한다.

3. 연구자
UConn 공개 자료 불러오기 → 조건별 조합 비교 → 보고서 다운로드 → 공개 모델 명시 실행 → Severson 열화 기록 확인 → 별도 공정 설계 수정·저장 → JSON 내보내기 → 모의 실행.
개선: 저장·가져오기 화면에서는 해당 작업의 도움말을 먼저 표시한다. 문서의 공정 설명 순서는 유지한다. 모의 실행 결과와 내보내기 버튼 사이 간격을 보완했다. 연구 결과와 개인 설계가 생산 기록에 자동 적용되지 않는 동선도 검증했다.

매뉴얼과 유지 관리
생산 재고·승인·연구 실행 결과의 매뉴얼 이미지를 갱신하고 승인 후 이동 방법을 문서에 반영했다. 역할별 연속 동선 회귀검사를 GitHub 배포 검증에 추가했다. 임시 캡처·중복 테스트 설정과 실패 로그를 정리하며 원본 고객 자료, 연구 자료, 제품 자산은 보존한다.

공개 체험의 기능 통과는 주성산업 팩의 수명·안정성 검증이나 현장 품질 승인을 의미하지 않는다.

로컬 결과: 브라우저 67건 통과, 단위 68건 통과, DB 통합검사 통과, 배포 범위 분류 2건 통과, TypeScript 검사 및 빌드 통과. 역할별 화면 증빙은 .local/role-review-20261017에 보관.
정리 결과: .local 내부의 임시 캡처·중복 설정·실패 로그 65개 제거. 이전 검증 기준 자료와 최신 역할별 화면 증빙, 고객·연구 원자료 보존.

후속 보완: 승인·반려·취소 후 남아 있던 검토 요청 문구를 처리 결과 안내로 바꿨다. 취소 상태의 요약 제목을 구분했다. 공정 배치 처리 후에는 팩 품질 지표 대신 공정 설계로 돌아가며, 팩은 품질 결과·검사 이력으로 이어진다. 취소 후 연구 복귀 회귀검사를 추가했다.
후속 검증: 320×480 전체 역할 동선 3건과 승인·역할 동선·매뉴얼 브라우저 검사 20건 통과.

추가 역할 시뮬레이션: 반복 업무와 중간 복귀
- 생산: 재고 2페이지에서 검색하면 첫 일치 셀을 건너뛰는 문제를 재현했다. 검색 변경·해제 시 첫 페이지로 돌아간다. 검색 결과가 없는 경우에서 복귀하는 동선도 확인한다.
- 품질: 의견 작성 후 승인 목록으로 돌아오면 입력이 사라지는 문제를 재현했다. 승인함 내부에서는 요청·검토자별 의견을 유지하고, 다른 요청에 섞이지 않도록 분리했다. 승인·반려 성공 시 초안을 비운다. 다른 업무 이동·새로고침 시에는 지워지는 범위를 화면에 안내한다.
- 연구: 동일 조건 재실행 및 이미 열린 실험 이력 재선택 시 결과로 이동하지 않는 문제를 재현했다. 완료·이력 선택마다 결과 화면을 연다.
- 1366px·390px에서 위 세 동선을 테스트하며 배포 전 자동 검사에 포함한다. 공개 체험 기반 검증으로, 실계정 서버 저장 검증과 구분한다.
추가 검증 결과: 신규 반복 업무 6건 통과, 기존 역할·승인·연구·반응형 검사 24건 통과, 단위 68건 통과. TypeScript 검사·프로덕션 빌드 통과. 품질 초안 복귀의 PC·모바일 화면 캡처 확인.
